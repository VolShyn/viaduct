# Community vs Cloud

Viaduct Community is the local editor in this repository.
[Viaduct Cloud](https://c4.quietgridlabs.com) is the hosted product for teams and agents.

| Capability | Community (this repo) | Cloud |
|---|---|---|
| C4 canvas L1–L4 | Yes | Yes |
| Markdown docs, PlantUML sequences | Yes | Yes |
| API endpoints / OpenAPI on containers | Yes | Yes |
| ER on datastores | Yes | Yes |
| Magic flows (edit, playback, generate sequence) | Yes | Yes |
| Domains as grouping inside one project | Yes | Yes |
| JSON import / export + browser persistence | Yes | Yes |
| Multi-tenant orgs & sharing | — | Yes |
| Realtime collaboration (Yjs) | — | Yes |
| Hosted MCP + personal tokens | — | Yes |
| Change sets + implementation bundle | — | Yes |
| Cross-project domain map / remote clones | — | Yes |
| Webhooks, Figma drift, AI assistant allowance | — | Yes |

The moat is **teams and agents on a shared model**, not the canvas itself.

Try Cloud: https://c4.quietgridlabs.com
